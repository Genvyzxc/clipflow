VIDEO TOOLS / FPS ANALYZER

FPS Analyzer.

TikTok動画のURLを入力できます。動画のFPS情報を取得できない場合は、保存済み動画ファイルを使って確認してください。

1. TikTok動画URL

この静的サイトはTikTokの動画データを直接取得するサーバーを持たないため、URLだけから正確なFPSを判定することはできません。URLの形式確認のみ行い、動画の解析にはファイルを選択してください。

2. 動画ファイルで確認

端末に保存した動画をアップロードすると、解像度・長さなどの読み取り可能な情報を表示します。

正確なエンコードFPSを表示するには、動画コンテナのフレーム情報を解析する専用ライブラリまたはサーバー処理が別途必要です。再生中の見た目だけから正確な元FPSとは断定しません。
VIDEO TOOLS / RESOLUTION

Resolution Check.

動画をアップロードすると、動画の幅・高さと縦横比を確認できます。

解像度はVideo Uploadページで表示されます。
VIDEO TOOLS / PIXEL UPSCALER

Pixel Upscaler.

動画を大きな解像度のキャンバスに拡大して書き出します。AIによるディテール復元ではなく、ピクセル数を増やす通常のアップスケールです。

1. 動画を選択

動画ファイルを選択してください。処理はこのブラウザ内で行います。

2. 出力解像度

縦動画は縦横比を維持して、長辺を選択したサイズに合わせます。

出力サイズ：未選択
動画を選択すると開始できます。
処理した動画をダウンロード
注意：拡大処理で解像度の数値は上がりますが、元動画にない細部が本物の情報として復元されるわけではありません。ブラウザや端末によっては高解像度の書き出しに対応しない場合があります。書き出し形式はWebMで、音声は端末・ブラウザが対応する場合のみ含まれます。
GV METHOD / ABOUT

About GV method.

動画の投稿準備とファイル情報確認のためのシンプルなワークスペースです。

Privacy

動画ファイルはこのページ内のブラウザ処理で確認し、外部サーバーへアップロードしません。

01 — SELECT

確認したい動画ファイルを選択します。

02 — CHECK

解像度・長さ・ファイル形式などを確認します。

03 — SAVE

必要なら元データを変換せずに端末へ保存します。
